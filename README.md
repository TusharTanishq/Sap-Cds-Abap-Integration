# Sap-Cds-Abap-Integration
End‑to‑end SAP S/4HANA project showcasing CDS views, AMDP table functions, OData auto‑publish, Fiori Elements preview, and ABAP ALV reporting. Includes interface CDS for purchase orders, a CDS table function with AMDP implementation, a consumption CDS view with metadata extension, and an ABAP SE38 program to consume CDS data in ALV.
